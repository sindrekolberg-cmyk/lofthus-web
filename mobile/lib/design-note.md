# Native design direction

The iPhone app should feel unmistakably like the Lofthus web product without copying desktop layout literally.

- warm paper base
- peach control-room surfaces
- near-black ink
- rust-red live accent
- editorial serif headlines (Georgia on iOS)
- condensed-feeling uppercase utility labels
- thin rules instead of excessive cards
- live scores high on the page
- league and month context close together
- Snakkiser as an editorial feed, not a dashboard grid
- native bottom navigation and touch behaviour

Shared data and semantics stay identical to web; layout is mobile-first.
